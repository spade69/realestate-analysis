# 学位分析交接：福田二手成交 × 学区

> 更新于 2026-11-02。新 session 处理学位/学区相关工作前先读这份。

## 已有的东西

| 文件 | 作用 |
|---|---|
| `ref/school_lists.json` | 66 所福田小学/初中的对口小区原文，来源是本地宝转载的福田教育网 **2023 年**数据，每条带来源 URL |
| `ref/school_map.csv` | 小区 → 对口小学 / 初中 + 学区档（名校 / 普通 / 无学位）+ 来源 + 备注。572 个小区按成交笔数降序；`tier` 为空 = 未标注 |
| `tools/build_school_map.py` | 按小区名匹配自动填 `school_map.csv`。`source` 以「人工」开头的行不覆盖；`OVERRIDES` 处理大学区（如益田村）；`PARTIAL` 标记部分楼栋对口 |
| `analyze.py` | `TOP_SCHOOLS`（名校名单，已确认）、`load_school_map` / `attach_school` / `analyze_school_premium`（同片区对比 + OLS 回归）/ `analyze_by_school`（各校上车门槛） |
| `render_site.py` + `template/index.html` | 站点「学区溢价」板块：分档概况、同片区对比、回归结论、名校逐校卡片、全部学校表；小区检索可搜学校名 |
| `tests/test_school.py` | 合成数据验证回归能还原已知溢价，并覆盖按学校聚合 |

流程：

```bash
python3 tools/build_school_map.py   # 重新匹配映射表
python3 render_site.py              # 生成 docs/
python3 -m pytest -q tests
```

## 当前结果

- 已标注 256 个小区，覆盖 **54%** 成交（1054 / 1962）。
- 回归（控制片区、期次、房龄、面积、户型）：名校相对普通学位单价 **+11.3%**（95% CI +3.2% ~ +20.0%，p = 0.005）。
- 名校上车门槛（2室及以上最低总价）：荔园(八卦岭) 186 万、荔园(通新岭) 208 万、福田区外国语小学 221 万、荔园外国语(天骄/狮岭) 320 万、百花 456 万、荔园(百花) 650 万。

## 待解决问题（按优先级）

1. **划片数据过时**：用的是 2023 年。2026 年《小一 / 初一新生报名地段代码图》是官方图片，**福田教育网等政府站从云端环境连不上**（白名单放行后对方仍断开连接）。需要用户提供截图，或换一个可访问的来源。
2. **46% 成交未标注**。高频未标注小区：财富广场(24)、京基滨河时代(19)、南天二花园(18)、京基御景华城(18)、花好园(17)、绿景虹湾(16)、赛格公寓(14)、星座大厦(13)、中洲滨海商业中心(12)、恒邦壹峯(12)、韵动家园(12)、莲花北村(11)、华新村(8)、海馨苑(8)。
   - **可直接修的匹配漏洞**：下沙小学名单写的是「下沙花好园」「滨河时代」，所以花好园、京基滨河时代没匹配上；南华小学名单里的「御景华城」对应京基御景华城。改匹配规则或加进 `OVERRIDES` 即可。
   - **缺学校页面**：福田小学、华新小学、景莲小学、梅林小学、福强 / 益田小学、东海实验小学等，本地宝上没有对口名单。
3. **「无学位」档未使用**：商住公寓、产权不足等目前混在「普通」里，需要规则或人工标注。
4. **共享学区 / 大学区**：福民片区（三校）、福田南片区、益田村大学区、香梅片区、梅林分享学区，现在一个小区同时计入多所学校，是否按学校分摊待定。
5. **部分楼栋对口**：国城花园仅 1、2 栋对口深圳实验学校小学部；园岭新村仅 1-62、92-97 栋对口园岭小学。成交记录没有楼栋信息，无法区分。
6. **初中维度未分析**：对口初中已部分填写，溢价分析目前只用小学。

## 环境注意

- 可访问：`sz.bendibao.com`、`m.bendibao.com`。不可访问：`m.wenda.bendibao.com`、`zs.szft.gov.cn`、`www.szftedu.cn` 等政府站。
- 本地宝站内搜索是 JS 渲染，抓不到；按文章编号 `https://m.bendibao.com/show{id}.html` 抓。2023 年福田学校对口页集中在 `923297`–`923800`（小学）和 `924352`–`924383`（初中），2025 年大学区 / 共享学区总览是 `977861`。
- 发布：分支开发 → PR 合并到 main（squash）→ GitHub Pages 自动部署，约 1 分钟。分支有新提交前先 merge 一次 main。
