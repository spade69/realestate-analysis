# 学位分析交接：福田二手成交 × 学区

> 更新于 2026-11-02（第二轮）。新 session 处理学位/学区相关工作前先读这份。

## 已有的东西

| 文件 | 作用 |
|---|---|
| `ref/school_lists.json` | 81 所福田小学/初中的对口小区原文，来源是本地宝转载的福田教育网 **2023 年**数据，每条带来源 URL |
| `ref/school_map.csv` | 小区 → 对口小学 / 初中 + 学区档（名校 / 普通 / 无学位）+ 来源 + 备注。561 个小区按成交笔数降序；`tier` 为空 = 未标注。行和 `n_deals` 由 build 脚本按 `data/` 重算 |
| `tools/fetch_school_pages.py` | 按本地宝文章编号抓对口名单页，写入 `school_lists.json`（遇 403 自动退避） |
| `tools/build_school_map.py` | 按小区名匹配自动填 `school_map.csv`。`source` 以「人工」开头的行不覆盖；`OVERRIDES` 处理大学区（如益田村）；`PARTIAL` 标记部分楼栋对口；`ALIASES` 处理名单与成交写法差异；`BRAND` 去开发商前缀兜底匹配；`NO_DEGREE_*` 是无学位推定规则 |
| `analyze.py` | `COMMUNITY_ALIASES`（小区名 OCR 误字统一，读入时生效，原始 CSV 不改）、`TOP_SCHOOLS`（名校名单，已确认）、`load_school_map` / `attach_school` / `analyze_school_premium`（同片区对比 + OLS 回归）/ `analyze_by_school`（各校上车门槛） |
| `render_site.py` + `template/index.html` | 站点「学区溢价」板块：分档概况、同片区对比、回归结论、名校逐校卡片、全部学校表；小区检索可搜学校名 |
| `tests/test_school.py` | 合成数据验证回归能还原已知溢价，并覆盖按学校聚合 |
| `tests/test_build_school_map.py` | 匹配规则（括号别名、品牌前缀兜底、ALIASES）、无学位规则、行重算 |

流程：

```bash
python3 tools/fetch_school_pages.py <id> ...   # 可选：补抓学校名单页
python3 tools/build_school_map.py   # 按 data/ 重算行 + 重新匹配映射表
python3 render_site.py              # 生成 docs/
python3 -m pytest -q tests
```

## 当前结果

- 已标注 342 个小区，覆盖 **72%** 成交（1433 / 1982，不含法拍）。名校 428 笔、普通 960 笔、无学位 45 笔。
- 回归（控制片区、期次、房龄、面积、户型）：
  - 名校相对普通学位单价 **+11.9%**（95% CI +5.8% ~ +18.5%，p < 0.001）。
  - 无学位相对普通 **−18.7%**（95% CI −25.3% ~ −11.5%）。只有 6 个小区、规则推定，参考价值有限。
- 名校上车门槛见站点「学区溢价」板块（按学校卡片）。
- 学校卡片 / 全部学校表只展示累计成交 ≥10 笔的学校（`analyze.SCHOOL_LIST_MIN_DEALS`），其余列在表下备注。按累计笔数计，导入新数据后门槛会变松，后续可改成月均口径。**溢价回归仍用全部样本。**
- 流通性（用户关心）：每校展示月均成交（一期 = 半月）、有成交期数 / 总期数、平均谈价率。不看成交周期（数据里没有这一列）。
